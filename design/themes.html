Every theme is the same set of 20 CSS variables prefixed --t- (terminal). Apply by setting data-theme="…" on the .tm root element. Variables not declared in a theme fall through to :root (amber). Each card below shows the full swatch grid, a live mini-mockup, and a copy-paste CSS block.
