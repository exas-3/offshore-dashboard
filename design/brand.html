Drop-in · Animated mark

Paste this anywhere you want the live beacon mark in the dashboard. CSS uses transforms only (rx/r animation isn't reliably supported in all browsers). SVG is inlined so author CSS hits the elements directly — no shadow-DOM workarounds.

/* CSS */ .meridian { transform-box: fill-box; transform-origin: center; animation: offshore-spin 6s ease-in-out infinite; } .beacon-dot { transform-box: fill-box; transform-origin: center; animation: offshore-dot 2.4s ease-in-out infinite; } .ring-a, .ring-b { transform-box: fill-box; transform-origin: center; animation: offshore-ring 2.4s ease-out infinite; } .ring-b { animation-delay: -1.2s; } @keyframes offshore-spin { 0%,100%{transform:scaleX(1)} 50%{transform:scaleX(0)} } @keyframes offshore-dot { 0%,100%{transform:scale(1);opacity:1} 15%{transform:scale(1.2)} 50%{transform:scale(1);opacity:.55} } @keyframes offshore-ring { 0%{transform:scale(1);opacity:.9} 100%{transform:scale(4);opacity:0} } <!-- HTML — inline SVG (not via <use>) --> <svg viewBox="0 0 64 64" width="56" height="56"> <rect width="64" height="64" fill="#000"/> <circle cx="32" cy="32" r="24" fill="none" stroke="#ffb000" stroke-width="2"/> <line x1="8" y1="32" x2="56" y2="32" stroke="#ffb000" stroke-width="2"/> <ellipse class="meridian" cx="32" cy="32" rx="10" ry="24" fill="none" stroke="#ffb000" stroke-width="2"/> <ellipse cx="32" cy="32" rx="24" ry="10" fill="none" stroke="#ffb000" stroke-width="1.5" opacity="0.55"/> <circle class="ring-b" cx="44" cy="22" r="4" fill="none" stroke="#ffb000" stroke-width="1"/> <circle class="ring-a" cx="44" cy="22" r="4" fill="none" stroke="#ffb000" stroke-width="1.5"/> <circle class="beacon-dot" cx="44" cy="22" r="4" fill="#ffb000"/> </svg> <!-- Favicon (static — browsers don't animate these reliably) --> <link rel="icon" type="image/svg+xml" href="assets/favicon.svg"> <link rel="apple-touch-icon" href="assets/apple-touch-icon.png">
